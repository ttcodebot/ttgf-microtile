# Micro tile: dense generated design

A Tiny Tapeout micro tile for gf180mcuD (`tt_um_micro_sweep`): A 28-flop generated design that fills 81 % of a micro tile.

- [Read the documentation for project](docs/info.md)

Built with the `microtile` branch of [tt-support-tools](https://github.com/ttcodebot/tt-support-tools/tree/microtile).
Four micro tiles are placed inside a 1x1 container project, see
[ttgf-microtile-container](https://github.com/ttcodebot/ttgf-microtile-container).
